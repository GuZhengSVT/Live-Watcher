# Live Watcher · 直播观测站

Live Watcher 是一款 macOS 菜单栏应用，用来查看关注的 B 站 UP 主是否开播、接收开播提醒和订阅主播周表。无需登录 B 站，通过UID或主页/直播间链接导入主播。

**0.1.1 测试版** · **macOS 14+**

[下载（GitHub Releases）](https://github.com/GuZhengSVT/Live-Watcher/releases) · [使用说明](<使用说明.md>) · [开发说明](<开发说明.md>)

## 已实现功能

- **直播状态**：通过 UID 或链接添加关注，定时或手动检测，正在直播的主播置顶，显示预览、标题、分区和同接，可直达直播间或 B 站动态。
- **开播提醒**：支持全局分区规则，也可为单个主播设置提醒。
- **周表订阅**：支持 HTTPS 和 webcal 日历链接，在时间线汇总日程。
- **外观**：支持日间、黑暗及跟随系统模式、五种配色和字号调整。
- **桌面小组件**：小、中、大三种尺寸，显示正在直播的主播。
